# DSL формул

Декларативный язык для описания вычисляемых полей в шаблонах вентиляторов.

## Назначение

Администратор в конструкторе шаблонов (Спринт 9) может создавать поля типа
`COMPUTED` с формулами. Формулы описывают, как вычислять значение поля из
других полей карточки. Формулы хранятся в JSONB-поле `FieldDefinition.formula`.

## Синтаксис

### Литералы

- Строки: `'текст'` (одинарные кавычки)
- Числа: `10`, `3.14`
- Boolean: `true`, `false`

### Поля

- `FIELD('key')` — значение поля карточки
- Если поле не задано явно, `FIELD` ищет среди системных вычисляемых полей

### Функции

Вызов: `NAME(arg1, arg2, ...)`. Имена регистронезависимы, приводятся к верхнему регистру.

## Словарь функций (25)

### Математические (7)

| Функция | Описание | Пример |
|---|---|---|
| `DIVIDE(a, b)` | Деление | `DIVIDE(225, 10)` → `22.5` |
| `MULTIPLY(a, b)` | Умножение | `MULTIPLY(3, 4)` → `12` |
| `ADD(a, b)` | Сложение | `ADD(3, 4)` → `7` |
| `SUBTRACT(a, b)` | Вычитание | `SUBTRACT(10, 3)` → `7` |
| `FLOOR(x)` | Округление вниз | `FLOOR(22.5)` → `22` |
| `CEIL(x)` | Округление вверх | `CEIL(22.5)` → `23` |
| `ROUND(x)` | Математическое округление | `ROUND(22.5)` → `23` |

### Строковые (5)

| Функция | Описание | Пример |
|---|---|---|
| `CONCAT(a, b, ...)` | Конкатенация | `CONCAT('A', 'B')` → `AB` |
| `UPPER(s)` | Верхний регистр | `UPPER('abc')` → `ABC` |
| `LOWER(s)` | Нижний регистр | `LOWER('ABC')` → `abc` |
| `TRIM(s)` | Убрать пробелы | `TRIM('  x  ')` → `x` |
| `FORMAT_NUMBER(x)` | Число → строка (5.6 → 5,6) | `FORMAT_NUMBER(5.6)` → `5,6` |

### Логические (8)

| Функция | Описание | Пример |
|---|---|---|
| `IF(cond, then, else)` | Условие | `IF(true, 'A', 'B')` → `A` |
| `EQUALS(a, b)` | Равенство | `EQUALS(380, '380')` → `true` |
| `NOT_EQUALS(a, b)` | Неравенство | `NOT_EQUALS(1, 2)` → `true` |
| `GREATER(a, b)` | Больше | `GREATER(5, 3)` → `true` |
| `LESS(a, b)` | Меньше | `LESS(5, 3)` → `false` |
| `AND(a, b, ...)` | Логическое И | `AND(true, false)` → `false` |
| `OR(a, b, ...)` | Логическое ИЛИ | `OR(false, true)` → `true` |
| `NOT(a)` | Отрицание | `NOT(true)` → `false` |

### Проверки (4)

| Функция | Описание | Пример |
|---|---|---|
| `EMPTY(x)` | Проверка на пусто | `EMPTY(FIELD('x'))` |
| `NOT_EMPTY(x)` | Проверка на непусто | `NOT_EMPTY(FIELD('x'))` |
| `DEFAULT(x, def)` | Значение по умолчанию | `DEFAULT(FIELD('x'), 'N/A')` |
| `COALESCE(a, b, c)` | Первое непустое | `COALESCE(FIELD('a'), 'X')` |

### MAP (1)

| Функция | Описание | Пример |
|---|---|---|
| `MAP(value, {k: v, ...})` | Маппинг значений | `MAP(380, {380: 'D', 220: 'E'})` → `D` |

## Примеры

### Маркировка размера колеса
FLOOR(DIVIDE(FIELD('wheelSize'), 10))

  225 мм → `22`, 315 мм → `31`.

### Код напряжения
MAP(FIELD('voltage'), {380: 'D', 220: 'E'})

  380 → `D`, 220 → `E`.

### Сборка маркировки 
CONCAT(
'VRK-PatAIR-',
FIELD('series'), '-',
FIELD('ductSize'), '/',
FLOOR(DIVIDE(FIELD('wheelSize'), 10)), '.',
FIELD('poles'),
MAP(FIELD('voltage'), {380: 'D', 220: 'E'})
)

Результат для PKV, 50-30, 225 мм, 2 полюса, 380 В:
`VRK-PatAIR-PKV-50-30/22.2D`.

## Ограничения

- Максимальная длина формулы: **5000 символов**.
- Максимальная глубина вложенности AST: **50**.
- Только белый список функций.
- Нет escape-последовательностей в строках (символ `'` в строке использовать нельзя).
- Нет циклов, рекурсии, условий уровня statement.

## Безопасность

DSL исполняется интерпретатором `FormulaEngineImpl`, который:
- Не использует SpEL, Groovy, JavaScript или другой ЯП.
- Не даёт доступ к Java-классам, рефлексии, файловой системе.
- Ограничивает глубину AST и длину формулы.
- Возвращает `null` вместо исключения при ошибке в COMPUTED-полях (мягкая деградация).

## Расширение

Новые функции добавляются в `FormulaFunctions` через `register(...)` — только разработчиком.
Расширение словаря для администратора — задача Спринта 9 (визуальный редактор).
